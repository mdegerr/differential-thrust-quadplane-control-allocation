# Sanitization Checklist

Before publishing this repository publicly:

- Remove all company names, case-study titles, logos, and interview-specific wording.
- Do not upload the original case-study PDF.
- Do not upload the original speaking-script PDF if it contains company or case references.
- Rename the final presentation PDF to a generic title, for example `quadplane_control_allocation_study.pdf`.
- Check PDF metadata for author, company, title, and hidden comments.
- Use only generic platform descriptions and illustrative parameters.
- Keep the repository title generic.
